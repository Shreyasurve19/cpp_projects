ENHANCED CALCULATOR: This project is a feature-rich calculator application developed using C++.
It performs basic arithmetic operations along with Modulus and Exponential.
Core concepts such as variables, data types, switch statements, conditionals(if/else), user input, mathematical functions, operators and error handling have been used in this project.

UNARY CALCULATOR: It is a simple program that performs mathematical operations requiring only one operand.
These operations include functions like square root, logarithm, negation, sine, cosine, etc.
